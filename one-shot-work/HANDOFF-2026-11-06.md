## PART 1 — The project in one paragraph

**STAGE TWO** is an interview take-home browser micro-game: one continuous experience —
cinematic rocket launch from a pad → stylized 4-beat transition into deep space → full-3D
chase-cam space shooter with a boss fight and a victory card. The owner's own GLB rocket
model is the hero asset. The entire game ships as **ONE self-contained HTML file**
(`E:\Game Build\index.html`, ~4.38 MB, generated) that runs by double-click from `file://`
with zero internet — Three.js r187, both GLBs (base64-inlined), fonts, and all game code
are inlined at build time. Reviewers play ~5 minutes and read the code + README
(README is a Stage 5 deliverable, not yet written).

## PART 6 — Core mechanisms, with code

### 6.1 The phase machine (`src/phases.js`) — everything hangs off this

```js
export function setPhase(name) {
  const hook = PHASES[name];
  if (!hook) { console.error(`[stage2] unknown phase "${name}" — refused`); return false; }
  if (hook.exit) hook.exit();                                   // ← exit-before-enter: the anti-leak contract
  ctx.probs.phase = name;
  for (const elm of ctx.OVERLAY_ELMS) elm.hidden = true;        // overlay sweep (story-001)
  document.body.classList.toggle('playing', PLAYING_PHASES.has(name)); // cursor:none
  hook.enter?.();
  return true;
}
```

`combat.exit = () => COMBAT.clearCombat()` — any exit drains every pool (no
spawn-during-restart). Modules get state through **ONE late-bound ctx object** filled in
main.js (scene-owned values are getters — consumers read CURRENT bindings, never stale
copies):

```js
const ctx = {
  SPIN, DT_CLAMP, RESTART_N, CORRUPT_GLB, ui, probs, game, OVERLAY_ELMS, input, mark, …
  get scene() { return scene; }, get camera() { return camera; }, get rocket() { return rocket; },
  get renderer() { return renderer; }, get composer() { return composer; }, …
};
initPhases(ctx); initInput(ctx); initLoop(ctx); initHud(ctx); initRocket(ctx);
```

### 6.2 The loop (`src/loop.js` via ctx) — dt clamp is the background-tab guard

```js
let dt = (ts - last) / 1000; last = ts;
if (!Number.isFinite(dt) || dt <= 0) dt = 0;   // NaN hygiene
if (dt > DT_CLAMP) dt = DT_CLAMP;              // DT_CLAMP = 0.05 — a backgrounded tab never teleports the world
if (paused) { last = ts; renderer.render(scene, camera); return; }

```

### 6.4 The fire path with the charged shot (`src/combat.js`) — story-018's keystone

One trigger (LMB **only** — Space is boost), two stages. Below `T_CHARGE = 0.6 s` of
continuous hold the stream is bit-identical to the shipped build; at the threshold the
stream suppresses and the charge fills; release fires exactly ONE charged bolt.

```js
const T_CHARGE = 0.6;          // s of continuous hold before suppression + charge fill (feel knob 0.45-0.9)
const CHARGE_DAMAGE = 6;       // elite-gunner one-shot anchor; boss weak point 6×3 = 18 (curve knob 4-8)
const SUPPRESS_STREAM = true;  // DESIGN CONST, not a knob: stream+charge together is a dominant strategy
const CHARGE_COLOR = 0xffc85a; // the amber family (the boss node's color language)

function spawnBolt(dmg, charged, dir) { …
  b.userData.dmg = dmg; b.userData.charged = charged;
  b.scale.setScalar(charged ? CHARGE_SCALE : 1);            // ×3, amber, same pool, same BOLT_SPEED 42
  b.material.color.setHex(charged ? CHARGE_COLOR : BOLT_COLOR); }

function fireTick(dt) {
  const input = C.api.input;
  const wantFire = input.fire;
  C.fireT -= dt;
  // pause cancel: the raw key set is the pause signal (zero cross-module change). The loop
  // halts tickCombat while paused, so the FIRST post-unpause tick still sees the key here.
  if (wantFire && !C.dead && (input.keys.has('KeyP') || input.keys.has('Escape'))) {
    C.chargeT = 0; C.charging = false;
  }
  if (!wantFire || C.dead) {                 // release / death:
    if (C.charging && !C.dead) {             // release AT/after threshold → exactly ONE charged bolt,
      spawnBolt(CHARGE_DAMAGE, true);        // latency ≤ 1 frame. Death fires NOTHING.
      C.fired.charged++; chargeRelease();
    }
    C.chargeT = 0; C.charging = false;
    return;
  }
  C.chargeT += dt;
  if (C.chargeT >= T_CHARGE) {
    if (!C.charging) { C.charging = true; chargeWhine(); }  // the crossing — the whine teaches it
    if (SUPPRESS_STREAM) return;
  }
  if (C.fireT > 0) return;
  C.fireT = C.effects.OVERDRIVE > 0 ? FIRE_INTERVAL / OVERDRIVE_DIV : FIRE_INTERVAL; // ÷2.2 ≈ 0.0568 s
  spawnStreamShot();
}
```

Every hit site reads the bolt's carried damage — `ENEMIES.hitDrone(d, b.userData.dmg || 1)`,
`DRONES.hitOrb(o, …)`, `BOSS.hitBoss(…, zone === 2, …)` — so `boss.js` stays zero-diff
(`hitBoss(dmg, isWeak, api)` already took a dmg param) and probe-spawned unstamped bolts
default to 1 (keeps bossProbe's ratio-3 exact).

**DPS parity anchor** (the load-bearing number): stream = 8 dmg/s; charged cycle ≈ 0.8 s
→ ≈ 7.5 dmg/s. Within ±15% — the charge converts spray-DPS into *alpha* (6 front-loaded),
it is not a DPS upgrade.

### 6.5 Pickups (`src/powerups.js`) — entity-side only, acyclic by construction

Imports `stage-two-lib` + `pool.js` ONLY; never reads combat state (combat.js composes the
`picked` api it calls back through). Drop sites: the two bolt-kill sites in combat.js ONLY
(raider + orb). Rams/dives self-kill inside enemies.js/drone.js → "on kill" reads as
"player-killed"; the boss is exempt from drops but effects still work during the boss fight.

```js
export const DROP_CHANCE = 0.18, PICKUP_LIFE = 8, PICKUP_BLINK = 2,
             PICKUP_RADIUS = 1.4, EFFECT_T = 8, PICKUP_POOL = 6;
const KINDS = ['SPREAD', 'OVERDRIVE', 'SHIELD'];   // uniform 1/3 kind roll

export function maybeDrop(pos) {
  if (!P.ready || !P.pool) return false;
  if (Math.random() >= DROP_CHANCE) return false;
  const kind = KINDS[(Math.random() * KINDS.length) | 0];
  spawnPickup(pos, kind); STATS.dropped++; STATS.byKind[kind]++;
  return true;
}
// tickPowerups(dt, playerPos, api): age/spin/blink-last-2s/despawn at 8 s, then
// pickup detection — FULL-3D squared distance (story-015 lesson: never XZ-only):
if (dx*dx + dy*dy + dz*dz < PICKUP_RADIUS * PICKUP_RADIUS) { P.pool.kill(it); STATS.picked++; api.picked(kind); }
```

Effect timers live in combat.js (`C.effects = { SPREAD, OVERDRIVE, SHIELD }`, seconds
left, ticked on scaled dt): SPREAD = 3-bolt fan ±6° (stream shots only — the charged bolt
is NEVER fanned); OVERDRIVE = stream interval ÷ 2.2 (`T_CHARGE` unchanged); SHIELD =
full shield + regen delay 0 for the window. Same-kind re-pickup REFRESHES to 8 s (never
stacks); different kinds run concurrently. Drop position arrives pre-clamped from
combat.js (r3 ≤ R_HARD − 1 = 79 — orbs can die outside the sphere; an unclamped drop
would be unreachable behind the hard clamp). HUD chips + charge ring are change-gated
DOM writes.

### 6.7 Arena + flight (Stage 3, the load-bearing geometry)

- Arena is a **soft sphere** centered O=(0,18,0), R_SOFT 60 (gentle 3 u/s bleed back) /
  R_HARD 80 (hard clamp); probes were re-derived r → r3 in story-016.
- `forward()` is full-3D: `(sin h·cos φ, sin φ, cos h·cos φ)` — velocity, bolts, camera
  and probes all inherit the vertical axis from this one function (story-015 keystone).
- Pitch on pointer-Y (direct) + R/F keys, ±72° envelope (no loops by design — camera
  up-vector safety). Drift = persistent velocity realigning to the nose
  (`ALIGN_RATE 4.5/s`, ≈26° slip at full turn; sustained-turn radius TIGHTENS to ≈6.9 u
  under drift — GDD errata, designer-adjudicated from measurement).
- All collision scans are full-3D squared-distance (the anti-camp fix; "never XZ-only"
  is a recorded lesson).
- Ship: MAX_SPEED 17; boost on Space; shield 50 → hull 100, regen after 3 s clean.
- Damage sources: raider contact 25, gunner/boss bolt 12, orb dive 25, boss dash 25.
- Score constants (combat.js): SCORE_DRONE 100, SCORE_GUNNER 150, SCORE_WAVE 150×w,
  SCORE_ORB 200. Boss: HP 60, WEAK_MULT 3, BOSS_WAVE 5 (spawns instead of wave 6).

   true red-first record; honesty fix landed. Mutation records are audited.

**Harness/environment traps — these WILL bite again if forgotten:**
1. **flow-check fixed-port trap**: flow-check spawns Edge on FIXED port 9941; a failed run
   can leave the whole Edge tree alive and the NEXT run's `/json/list` answers from the
   STALE tree (symptom: `FAIL poll timeout`, `0 passed, 0 failed`). After ANY failing run:
   `taskkill` lingering `*edge-profile*` msedge trees, verify `netstat :9941` free, re-run.
   New harnesses: RANDOM ports (cdp-check style), never fixed.
2. **CDP reply shape** is `r.result.value` — `r.result.result.value` always throws.
3. **IPv6-first CDP connect**; match page targets by **URL PREFIX** (never index — the
   first target can be `edge://sync-confirmation-dialog` or a stale page).
4. **Headless GLB decode blocks the main thread** — fixed short sleeps evaluate too early;
   use long waits (25 s+) + phase polling. `--virtual-time-budget` is consumed by the
   decode — phase walks never start under it.
5. **Headless fps 9–17 under load** — game-time lags wall-clock; probes need
   proportionally longer waits.
6. **A closed Edge window drains the event loop** → "unsettled top-level await" exit
   unless sends have timeouts + ws close detection.
7. **Live-tab rAF freezes when the browser window is unfocused** (`hasFocus()=false`) —
   keep it foreground for live visual checks; back-to-back evaluate polling starves rAF.
8. **`--dump-dom` is empty on this Edge build**; `--screenshot` works but PNGs are
   owner-facing artifacts only — the AI verification gate is CDP `Runtime.evaluate`.
9. **Orphaned headless Edge processes** — `child.kill()` leaves the tree alive; cleanup is
   `taskkill /F /T /PID` + unique `--user-data-dir` per run. Nuke strays via
   `Get-CimInstance Win32_Process` filtered by `CommandLine -like '*edge-profile*'`.
10. **Heredoc/Write-tool backslash rules** on Windows paths; **perl multiline misses on
    CRLF** — prefer the Edit/Write tools over in-place shell sed/perl.
11. **Boot timing (real numbers)**: headed cold 6.6 s was 3.4 s HTML+bundle parse +
    3.1 s localStorage first-touch stall + 0.4 s rest; GLBs 0.18 s (exonerated). The
    lazy-storage fix (story-007) landed; MODULE→TITLE is now 600 ms headed (band < 1000).
    The 55–60 s headless figure was never reproduced.
12. **Agent quota ghost runs** — quota errors can arrive AFTER a subagent finished (it may
    have committed/merged/tagged): check `git log` before re-dispatching. A USER-REJECTED
    dispatch leaves mid-mutation state — run the full battery + inspect the diff after ANY
    interruption (this happened in Stage 3; the merged-master battery caught the leftover).
13. **Quota can recover same-day** — a cheap "reply OK" probe dispatch tests it first.
